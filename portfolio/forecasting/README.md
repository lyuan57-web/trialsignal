# Forecasting the U.S. Unemployment Rate

Time-series forecasting study of monthly U.S. unemployment using ARIMA and exponential-smoothing models in R. The analysis compares alternative specifications through residual diagnostics and out-of-sample forecast accuracy.

- [Read the report](./us-unemployment-forecast-report.pdf)
- [View the code and model output](./us-unemployment-forecast-code.pdf)

## Methods

R, time-series diagnostics, ARIMA, exponential smoothing, and forecast evaluation.
